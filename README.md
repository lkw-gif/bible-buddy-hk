# 聖經有幾熟？｜Bible Buddy

港式口語聖經知識 web app。為教會小組、主日學熱身和個人溫習而設；以聖經基本知識為主，另有神學、教會歷史及原文。

公開網站：https://lkw-gif.github.io/bible-buddy-hk/

另一公開網址：https://bible-buddy-hk.lui-david-1529.chatgpt.site

兩個網址都可以直接開啟。程式碼、240題基礎題庫、40題進階題庫、100題教會歷史操練、100題聖經知識操練及可愛小羊插圖一併存放喺呢個儲存庫。

## 八個測驗方向

| 方向 | 內容 | 題數 |
| --- | --- | ---: |
| 聖經打地基 | 書卷、編目、文體、閱讀方法 | 30 |
| 舊約行曠野 | 創造、立約、出埃及、王國、被擄與歸回 | 30 |
| 新約跟主行 | 耶穌生平、比喻、使徒行傳與書信 | 30 |
| 信心人物簿 | 熟悉人物及容易忽略的同工 | 30 |
| 金句唔亂拎 | 金句的前後文、文體及原來對象 | 30 |
| 信仰觀念扎根 | 恩典、救恩、三一、基督論、教會與終末 | 30 |
| 教會歷史入門 | 大公會議、改革、中文譯本與合一運動 | 30 |
| 聖經原文入門 | 希伯來文、亞蘭文、希臘文及字義方法 | 30 |

綜合題庫共 240 道原創粵語單選題，每個主題分 10 題低、10 題中、10 題高試探。所有題目均有解說；經文出處同參考資料保留於題庫原稿供核對，遊戲介面唔顯示出處或參考連結。原創題幹及評語，沒有複製網上題庫或其他專案程式碼。

## 可以怎樣玩

- **曠野快閃（General 20題）**：基礎10／中等8／稍深入2。八個主題各2–3題，每個主題至少1題基礎、1題中等；隨機揀四個主題加題，其中兩個加基礎題、兩個加稍深入題。
- **曠野長征（General 40題）**：基礎20／中等16／稍深入4。每個主題5題，每個先抽2基礎、2中等，再隨機四個主題加基礎題，其餘四個加稍深入題。兩款General均從原240題抽選，以基礎聖經知識為主，九成題目為基礎或中等。
- **主題練習**：揀主題即開始10題混合難度練習。
- **曠野試探場**：低「少少試探」、中「開始有啲 feel」、高「就嚟頂唔住」。選級直接答題，每場16題，每個方向各2題，全部使用所選難度。高難度使用40題專用進階池；低及中繼續使用原有相應程度題庫。
- **教會歷史篇（100題操練）**：獨立10課，每課10題；按初期教會、信經、中世紀、宗教改革、宗派、復興宣教、中國、香港、二十世紀、閱讀史料嘅順序學習。每題答後即顯示原創粵語解說；主要資料同核對連結保留於題庫原稿，唔喺遊戲畫面顯示。儲存逐題進度，可續玩、重做一課、直接下一課，亦接駁收藏同錯題溫習。100題全部可做，不混入General抽題配額。
- **舊約書卷：創世記**：100道經文題分10課，每課10題，另設從100題隨機抽取的10題測驗。每題附解說，課程進度獨立儲存；題庫原稿及出處見 `research/genesis-a.json` 與 `research/genesis-b.json`，修改後執行 `node scripts/build-genesis.mjs`。
- **錯題與收藏**：完成後自動收集錯題及跳過題；再次答對會移出錯題集。可獨立收藏題目。
- **聖經知識（100題操練）**：入口喺教會歷史旁邊，分10課，每課10題。涵蓋新舊約卷數、律法書、歷史書、詩歌智慧書、大小先知、四福音與使徒行傳、保羅書信、其他書信與啟示錄，以及基本人物和讀經方法。按新教常用66卷目錄及分類編排，每題有粵語解說；支援上一題、續玩、下一課、收藏及錯題重溫。逐題進度與教會歷史分開儲存，100題不混入General或試探場題庫。
- **成長紀錄**：本機保留最近60局，支援續玩、分項成績、建議閱讀及成績TXT下載。
- **統一幽默口吻**：按測驗就直接答題，不設評語或設定選擇頁。
- **上一題**：作答期間可往返已答題目查看原答案與解說，亦可於返睇時儲存及續玩；已提交答案保留，避免重複計分。回到未答位置後可繼續作答。
- **無倒數壓力**：可跳過、用鍵盤1–4或A–D答題、Tab／Enter操作，支援減少動態效果偏好。

General 20題每題5分，40題每題2.5分；80分仍須答啱32／40題。稱號仍然只有8個，沒有為加難而更改分數或門檻。稱號分數依次為0、20、40、55、70、80、90、97：初信探索級、讀經起步級、信咗一排級、神學生挑戰級、牧會研究級、牧師挑戰級、神學老師挑戰級、神學家彩蛋級。這些是知識遊戲稱號，不推斷真實信仰年資、靈命、事奉或學術資格；其餘模式不頒發General稱號。

## 內容及參考

互動構思參考：

- [GitHub Bible-Quiz](https://github.com/fwesh001/bible-Quiz/)：分類、難度、每日挑戰及答後解說。
- [Bible Gateway Quizzes & Games](https://www.biblegateway.com/blog/category/quiz/)：主題小測。
- [BibleProject How to Read the Bible](https://bibleproject.com/videos/collections/how-to-read-the-bible/)：文體、敘事與上下文學習。

內容出處按每題獨立連結：

- 聖經題以香港常用中文卷名及經文章節為依據，經文連到Bible Gateway和合本。
- 編目題明確指定新教常用編目；不把66卷說成所有教會的唯一編目。
- 神學差異題標明經典三一／迦克墩等表述及不同宗派的實踐，避免預設單一宗派答案。
- 歷史查閱CCEL、New Advent歷史文獻、OCA、WCC、香港聖經公會、日內瓦檔案、宗派官方歷史及圖書館實物資料。
- 原文詞義查閱Bible Hub收錄的Strong、Thayer及BDB等詞典條目；題目強調語義須按上下文判斷。

已檢閱全部240題嘅題幹及選項，集中修正題幹透露答案及難明用字；56題另有明確文字修訂，包括移除「十二使徒」數量提示、唔喺題幹講出好撒馬利亞人及日內瓦學院嘅答案線索，並將「唔宜簡化」「近文」「語義範圍」換成自然粵語。保留神學、歷史、原文題所需嘅專有名詞；難度來自知識同相關干擾選項，唔靠拗口字眼。舊題庫版本繼續供已儲存局數及成績使用。

全站介面已將「瓣」「乾糧上枱」「囫圇吞棗」等唔易明嘅字眼換成「主題」「諗深一層」「睇清楚用字同前後文」等自然講法，亦將錯題與書籤入口改為「溫習角落」。

General已調回較多基礎聖經知識；原本40題進階版嘅專用題庫，改供獨立試探場高難度使用。題庫內容與覆核記錄見 [research/CHALLENGE-REVIEW.md](research/CHALLENGE-REVIEW.md)。既有一般／進階40題、舊試探場進度及成績繼續可讀，按原題評分。

網站不設題庫手冊或答案總覽；教會帶領者可在本儲存庫檢閱完整題庫及參考連結。

## 本機執行及驗證

Node.js 24.15以上（或相容的22.22.2以上版本）。網站本身沒有執行期依賴；jsdom僅用於開發測試。

```sh
npm ci
npm start
# 開啟 http://127.0.0.1:4173/
npm run check
```

`dist/`可由任何支援ES modules的靜態主機提供；不要以file://直接開啟模組。

## GitHub Pages 發佈

`.github/workflows/pages.yml` 會在每次推送到 `main` 後安裝開發依賴、執行題庫與功能測試，通過後才將 `dist/` 發佈至 GitHub Pages。也可以從 Actions 手動執行同一個流程。

題庫位於 `dist/questions.mjs`。修改內容後推送到 `main`，網站就會隨成功的工作流程更新。純靜態網站沒有伺服器密鑰或執行期套件依賴。

驗證包括240題結構及分級完整性、兩款General全部62種可能分數、試探場固定難度與平均分配、20題版加題方向隨機輪換、40題版固定配額、三段試探程度與舊紀錄保留、跳過、防重複提交、錯題移除及已存進度驗證。DOM流程測試執行真實app模組及點擊／輸入事件，覆蓋完整20／40題交卷、稱號、分享／下載入口、主題設定、續玩、試探場分級、重試及成績、收藏及簡化介面。

目前共34項功能測試，另有580題結構、來源及資料一致性檢查。覆蓋General九成基礎及中等題、試探場高難度專用池、上一題往返／重新整理／續玩與分數保持一致，以及舊版40題和試探場紀錄保留。兩篇課程各100題逐課完成、獨立進度及錯題重溫亦有DOM流程覆蓋。教會歷史覆核見 [research/HISTORY-REVIEW.md](research/HISTORY-REVIEW.md)，聖經知識見 [research/BIBLE-REVIEW.md](research/BIBLE-REVIEW.md)。

當次環境的Work設定停用了本機瀏覽器自動操作，互動流程採用DOM整合測試，並另核對平台產生的桌面首頁截圖。jsdom不驗證CSS排版或原生對話框／剪貼簿的真實裝置行為；手機及真實瀏覽器全流程仍須作最後視覺驗收。

## 儲存及維護

作答資料、最多60局紀錄、錯題及收藏僅存在瀏覽器localStorage。沒有跨裝置同步、使用者帳號系統、伺服器排名或蒐集教會身份。Sites存取閘口是外層平台設定，不是測驗的帳號功能。

`dist/bible-course.mjs`管理聖經知識課程，三份 `research/bible-{basics,ot,nt}.json` 保存100題原稿與逐題核對來源；修改後執行 `node scripts/build-bible.mjs` 產生 `dist/bible-data.mjs`。卷數明確按新教常用目錄，普通書信七卷不含希伯來書；這些資料保留於原稿，介面只顯示解說。

`dist/challenge-data.mjs`由兩份 `research/challenge-*.json` 經 `node scripts/build-challenge.mjs` 產生，專供獨立試探場高難度使用。`dist/history-course.mjs`管理課程及進度，三份 `research/history-*.json` 管理100題歷史原稿；修改後執行 `node scripts/build-history.mjs`。`dist/questions.mjs`管理綜合題庫，`dist/choices.mjs`管理相關干擾選項，`dist/copy-edits.mjs`管理口語及防漏答案修訂，`dist/engine.mjs`處理抽題與評分，`dist/app.mjs`處理介面及本機進度。加入新題時同步更新數量規格及測試，並保留可查證出處。
